# QR Code Generator

A simple web-based QR Code Generator built with Python and Flask.

Users can enter a website URL, generate a QR code, preview it, and download it as a PNG image.

## Features

- Generate QR codes from website URLs
- Preview generated QR codes
- Download QR codes as PNG images
- URL validation
- Simple, responsive dark-themed interface

## Technologies

- Python
- Flask
- qrcode
- Pillow
- HTML
- CSS

## Installation

Clone the repository:

```bash
git clone https://github.com/yam-72/qrcode-generator.git
cd qrcode-generator
```
